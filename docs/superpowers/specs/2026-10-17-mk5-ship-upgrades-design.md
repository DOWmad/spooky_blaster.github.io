# MK5 Ship Upgrades

Extend the existing ship ladder from MK3 to MK5. The player still starts at MK1 and gains one class per `UPGRADE` pickup. Each class increases keyboard movement speed and shield capacity; the pickup fills shields to the new capacity.

| Class | Speed | Maximum shields |
| --- | ---: | ---: |
| MK1 | 260 | 2 |
| MK2 | 290 | 3 |
| MK3 | 320 | 4 |
| MK4 | 340 | 5 |
| MK5 | 360 | 6 |

Add visibly distinct MK4 and MK5 pixel-art hulls in both classic and Halloween themes. Keep the player's small hitbox, weapon levels, pickup odds, and controls unchanged. A death drops one class and clears shields as before. Further upgrade pickups at MK5 award 5,000 points.

The new classes give guaranteed boss upgrade drops a purpose later in the first campaign without creating another control or weapon path.
